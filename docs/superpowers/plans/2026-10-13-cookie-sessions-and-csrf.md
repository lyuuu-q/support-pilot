# 浏览器 Cookie 会话与 CSRF 防护执行计划

**目标：** 让浏览器端令牌不再暴露给页面 JavaScript，并支持即时撤销与刷新轮换。
**ADR：** `docs/adr/0016-cookie-sessions-and-csrf.md`

## 步骤

- [x] 新增 `auth_sessions` 表与迁移 0012；
- [x] 会话服务：创建、查找、轮换、撤销、CSRF 校验；
- [x] 访问令牌绑定 `sid` 并在 Cookie 路径强制校验会话状态；
- [x] 登录/刷新/登出三个接口与 Cookie 读写；
- [x] 依赖层接入 Cookie 认证与写操作 CSRF 校验；
- [x] 前端切换到 Cookie 会话（api 层、App 启动恢复、登出）；
- [x] 脚本与 demo 显式使用 `session_mode="token"`；
- [x] 集成测试、前端单测、浏览器端到端回归；
- [x] 更新 ADR、评测、验收和学习文档。

## 完成定义

- [x] 登录响应不再包含访问令牌；
- [x] 无 CSRF 头的写操作被 403 拒绝；
- [x] refresh 轮换后旧令牌重放被 401 拒绝；
- [x] 登出后旧访问令牌立即失效并留审计；
- [x] 前端在任何地方都不再保存令牌；
- [x] 全量后端、前端与浏览器测试通过。
