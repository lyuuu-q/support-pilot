# 会话生命周期管理与清理执行计划

**目标：** 让浏览器会话可查看、可单独撤销、可一键全部撤销，并避免会话表无限增长。
**ADR：** `docs/adr/0017-browser-session-lifecycle-and-pruning.md`

## 步骤

- [x] 会话保留配置与批量上限；
- [x] `prune_auth_sessions`（只删除 cutoff 前已过期的行，默认 dry-run）；
- [x] 会话列表 / 撤销单个 / 全部撤销三个接口与契约；
- [x] 审计事件与三个会话指标、`auth.sessions.prune` Span；
- [x] `scripts/prune_auth_sessions.py` 与维护脚本两段式执行；
- [x] 前端"登出所有设备"入口；
- [x] 集成、清理、观测、前端与浏览器测试；
- [x] 更新 ADR、评测、验收与学习文档。

## 完成定义

- [x] 活跃会话永不被清理（无论状态）；
- [x] dry-run 不修改数据且给出删除量；
- [x] 只能撤销自己的会话，跨账号返回 404；
- [x] 全部撤销后旧访问令牌立即失效；
- [x] 维护脚本一条命令覆盖两段清理并留日志；
- [x] 全量后端、前端、浏览器测试通过。
